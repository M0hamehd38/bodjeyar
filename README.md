# بودجه‌یار

ابزار تصمیم مالی برای مدیر مجموعه: بودجه‌ریزی مرحله‌به‌مرحله با تأیید مدیر، ثبت عملکرد واقعی ماهانه و قبوض، گزارش انحراف با علت و اقدام، اصلاحیه بودجه، پیگیری سرمایه‌گذاری و نُه گزارش مدیریتی با خروجی Excel و PDF.

رابط کاربری و هویت بصری همان **دیزاین سیستم سایپا نمایندگی استوار** است — همان پوسته‌ی «میز کار سازمانی» (HooshSazmani) و «ارزشیابی عملکرد» (Arzeshyabi): نوار کناری سرمه‌ای با نوار مورب نارنجی، فونت Estedad، نارنجی آرم `#FF7900` و سرمه‌ای پوستر `#0D2041`، کارت‌ها، PageHeader با نوار نارنجی، و زبان بصری AiAssist فقط برای قابلیت‌های هوشمند.

## اجرا

```
npm install
npm run dev
```

سپس `http://localhost:3000`. بار اول صفحه‌ی راه‌اندازی باز می‌شود: حساب مدیر مجموعه (و در صورت تمایل حسابدار) ساخته می‌شود و می‌توانید با داده‌ی نمونه‌ی نمایندگی شروع کنید.

## ورود داده از فایل اکسل

تنظیمات › داده‌ها › «ورود از فایل اکسل اطلاعات اولیه»: فایل «چک‌لیست جمع‌آوری اطلاعات اولیه بودجه نمایندگی» را بدهید تا همه‌ی بخش‌ها با همان ارقام ساخته شوند — مراکز درآمد (کمیسیون هر خودروساز، گارنتی، وارنتی، صافکاری، بیمه، سود سپرده) و مراکز هزینه، سرفصل‌های استاندارد، عملکرد ماهانه (درآمد، هزینه، حقوق)، ریز هر سند با شرح اصلی، قبوض، دفتر حقوق نفر به نفر، خریدهای سرمایه‌ای، مطالبات و حساب‌های پرداختنی، و پیش‌نویس بودجه‌ی دوره‌ی بعد از روی میانگین عملکرد. تبدیل قطعی است (`src/lib/import-xlsx.ts`)، در مرورگر انجام می‌شود و هر فرضی که گرفته شد به‌صورت هشدار نمایش داده می‌شود.

همین تبدیل از خط فرمان هم فایل پشتیبان می‌سازد (برای «بازیابی از پشتیبان»):

```
npx tsx scripts/import-xlsx.mts <file.xlsx> budgetyar-backup.json
```

داده‌ی واقعی (اکسل و پشتیبان) در مخزن ذخیره نمی‌شود (`.gitignore`).

## هوش مصنوعی — ایجنت مالی و دو مدل

مثل «هوش سازمانی» دو مدل داریم و مدیر در تنظیمات › هوش مصنوعی برای هر کار یکی را انتخاب می‌کند:

- **مدل دقیق** — `GPT-5.6-Luna` (همان مدل «گام»): ایجنت، ساخت بودجه، خواندن سند، اصلاحیه
- **مدل روزمره** — `DeepSeek-V4-Flash` (همان مدل «ارزشیابی»): دستیار صفحه‌ها، گفت‌وگو، خلاصه‌ها

فایل `.env.local` را از روی `.env.example` بسازید؛ نام متغیرها همان هوش سازمانی است (`ARVAN_AI_API_KEY`، `ARVAN_PRECISE_MODEL`، `ARVAN_EVERYDAY_MODEL`، و کلید جدای هر مدل `ARVAN_PRECISE_AI_API_KEY` / `ARVAN_EVERYDAY_AI_API_KEY`). OpenAI و Anthropic هم پشتیبانی می‌شوند (`AI_PROVIDER`). بدون کلید، بخش‌های هوشمند پنهان می‌مانند و بقیه‌ی برنامه کامل کار می‌کند.

**ایجنت مالی (`/agent`)** — Agent as a Service برای مدیر مالی، حسابدار و مدیر کسب‌وکار: ۱۵ ابزار فقط‌خواندنی (سود و زیان ماهانه، ترکیب درآمد و هزینه، سودآوری واحدها، ریز اسناد، بودجه در برابر عملکرد، پیش‌نویس بودجه، حقوق پرسنل، قبوض، مطالبات و بدهی‌ها، سرمایه‌گذاری، پیش‌بینی، کیفیت داده، …) و ۴ ابزار «پیشنهاد» (تغییر بودجه‌ی پیش‌نویس، علت انحراف، برنامه‌ی پیگیری حساب، کار برای تیم). پیشنهادها فقط با «اعمال» کاربر ثبت می‌شوند. هشت مأموریت آماده: بستن ماه، گزارش مدیریتی، تدوین بودجه، وصول و پرداخت، کاهش هزینه، حقوق، پیش‌بینی، انحراف.

**دستیار هر صفحه** — دکمه‌ی شناور «دستیار» در همه‌ی بخش‌ها: همان ایجنت با زمینه و پیشنهادهای همان صفحه.

نام پرسنل پیش از ارسال به مدل با `[[P#]]` جایگزین و در پاسخ برگردانده می‌شود. ابزارها در مرورگر روی داده‌ی همان کاربر اجرا می‌شوند؛ سرور فقط یک دور مدل را اجرا می‌کند و کلید هرگز به مرورگر نمی‌رود.

## بخش‌ها

| مسیر | بخش |
|---|---|
| `/` | داشبورد مدیریتی: کاشی‌های درآمد، هزینه، نتیجه و تحقق؛ نمودار ماهانه؛ سه هشدار مهم؛ سهم درآمد؛ وضعیت واحدها؛ پرسش از داده‌ها |
| `/budget` | دوره‌ها، نسخه‌ها، تأیید مدیر، سناریوها و ویزارد شش‌مرحله‌ای (دوره، درآمد، هزینه، حقوق، سرمایه‌گذاری، بررسی) با دستیار گفت‌وگو |
| `/actual` | عملکرد واقعی ماهانه، قبوض مستقیم و مشترک، بستن و بازکردن ماه، ثبت از روی عکس یا متن سند |
| `/variance` | انحراف‌ها با وضعیت سبز/زرد/قرمز، ثبت علت و اقدام، پیشنهاد علت با هوش مصنوعی |
| `/revisions` | تاریخچه‌ی نسخه‌ها، اصلاحیه با دلیل، مقایسه‌ی دو نسخه، پیشنهاد اصلاحیه از روی روند |
| `/investment` | پروژه‌های سرمایه‌گذاری، زمان‌بندی، پیشرفت و هزینه‌ی واقعی |
| `/reports` | نُه گزارش با فیلتر ماه و مرکز، خلاصه‌ی نوشتاری، خروجی Excel و PDF |
| `/agent` | ایجنت مالی: مأموریت‌های آماده، گفت‌وگو با ابزار، صندوق پیشنهادها و کارها، وضعیت دو مدل |
| `/entries` | ریز اسناد: هر ردیف فایل حسابداری با شرح اصلی، سرفصل و مرکز |
| `/accounts` | مطالبات و حساب‌های پرداختنی: مانده، تمرکز، وضعیت و برنامه‌ی پیگیری |
| `/staff` | پرسنل و حقوق: دفتر حقوق نفر × ماه، ردیف‌های ناهمخوان، مقایسه با حقوق حسابداری |
| `/settings` | هویت سازمان، آستانه‌ها و سناریوها، مراکز و سرفصل‌ها، کاربران، ورود اکسل، پشتیبان و بازیابی، مدل‌های هوش مصنوعی، رویدادها، حساب من |

نقش‌ها: **مدیر مجموعه** (تأیید، تنظیمات، بازکردن ماه) و **مدیر مالی / حسابدار** (تدوین بودجه، ثبت عملکرد، علت انحراف، سرمایه‌گذاری، اصلاحیه).

## ساختار

| مسیر | محتوا |
|---|---|
| `src/app/(app)/` | صفحه‌های برنامه پشت پوسته‌ی وارد‌شده |
| `src/app/login/` | ورود و راه‌اندازی اولیه |
| `src/app/api/ai/` | مسیر سرور هوش مصنوعی: دو مدل، ابزار (tool calling)، تصویر |
| `src/lib/ai-server.ts` | درایورهای آروان/OpenAI/Anthropic و تنظیمات محیطی |
| `src/lib/ai-purposes.ts` | کاربردهای هوش مصنوعی و مدل پیش‌فرض هر کدام |
| `src/lib/agent.ts` | ایجنت مالی: ابزارها، نام‌مستعار، حلقه‌ی ایجنت و مأموریت‌ها |
| `src/lib/import-xlsx.ts` | ورود قطعی فایل اکسل اطلاعات اولیه |
| `src/components/ui` | اجزای دیزاین سیستم: Button، Card، Badge، Alert، Field، PageHeader، Stat، Segmented، Tabs، Modal، EmptyState، Loading |
| `src/components/app-shell.tsx` | نوار کناری و سربرگ، همان پوسته‌ی میز کار سازمانی |
| `src/components/ai-assist.tsx` | زبان بصری هوش مصنوعی (ai-surface، ai-btn، ai-chip) |
| `src/lib/ledger.ts` | محاسبه‌ی بودجه در برابر عملکرد، وضعیت، سناریو و اعتبارسنجی |
| `src/lib/store.tsx` | وضعیت برنامه، همه‌ی نوشتن‌ها و Audit Log |
| `src/lib/backend.ts` | لایه‌ی ذخیره (فعلاً حافظه‌ی مرورگر؛ برای سرور مشترک همین رابط با API پیاده شود) |
| `src/lib/format.ts` | تقویم شمسی، ارقام فارسی و مبلغ BigInt تومان |
| `src/lib/report.ts` | گزارش‌ها و خروجی Excel و PDF |
| `public/fonts`، `public/brand` | فونت‌های Estedad و Parastoo و آرم سایپا از دیزاین سیستم |

مبلغ‌ها همیشه BigInt تومان‌اند، نه عدد اعشاری. داده‌ی ثبت‌نشده هرگز «۰» نشان داده نمی‌شود.

دوره‌ای که عملکرد دارد ولی بودجه ندارد (مثلاً شش‌ماهه اولِ واردشده از اکسل) «دوره‌ی مرجع» است: داشبورد، عملکرد، گزارش‌ها و سرمایه‌گذاری با عملکرد واقعی کار می‌کنند و انحراف/اصلاحیه فقط برای دوره‌ی دارای بودجه‌ی تأییدشده است.
